## What was built today

- **Backend.** Two Edge Functions:
  - `mm-client` (anonymous, authorised per record by a one-time token) handles consent wording, consent registration, identity questions, and expiring an abandoned question round.
  - `mm-staff` (signed-in staff only) handles running the credit check, fetching the PDF, refreshing consents, recording withdrawals, retrying registration, clearing a system error, recovering stalled records, and deleting a record together with its PDF.
  - Both run on eight shared modules and 46 Deno tests (`cd supabase/functions && deno test --allow-read _shared/`).
- **Database.** Migration `20260926_mortgagemax.sql` is **applied**. `20260927_hardening.sql` is **written and locally tested, not applied**.
- **Browser.**
  - `store.js` is rewritten.
  - `index.html` renders MortgageMAX's live consent wording with a Pro Mortgages SA notice, and has the new identity-question screen.
  - `admin.html` can run a credit check (with a confirm step and an audited identity override) and shows a three-tier report card, the consent history, the identity-check state, a withdrawal flow, staff profiles, and a "Needs attention" tile for stalled records.

## Deliberately deferred (documented, not forgotten)

- **Audit-trail race.** Two changes landing on the same record in the same instant can lose one audit line; the status is never wrong. Low severity. The fix is an SQL helper for atomic appends.
- **Passport applicants** go to manual handling until MortgageMAX confirms passport support (`ALLOW_PASSPORT=false`, enforced on the server too).
- **ID copies to MortgageMAX:** kept in our bucket only. Whether they want them via `POST /Consents/Files` (the request takes only a file — no link to a person) is question 4 in the Louis email.
- **Orphaned uploads:** an ID copy whose `manual-verify` never arrives (e.g. dropped connection) stays under the ref's folder until `delete-record` sweeps it. Logged, not auto-pruned.
- **Never tested live:** the identity questions (`/Idv/getQuestions` returns `NoQuestionsFound` for both test IDs — row 4c). `/CreditCheck/full` and `getDocument` were proven live on 28 Sep.
- **Backups do not cover stored files** (Supabase docs, checked 30 Sep: "Database backups do not include objects you store via the Storage API"; Pro keeps 7 daily backups; point-in-time recovery is a paid add-on). Report PDFs can be fetched again from MortgageMAX by `groupId`; **ID copies cannot**. Decide whether that is acceptable before go-live; it feeds Operator Agreement clause 11.
- **Stale PDF detection** measures from when the report arrived, not from when the PDF fetch began. Minor.
